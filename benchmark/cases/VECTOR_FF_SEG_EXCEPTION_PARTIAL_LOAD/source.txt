Source: RISC-V Unprivileged ISA Manual, unpriv/vector-common.adoc (fault-only-first segment loads)

For fault-only-first segment loads, if an exception is detected partway
through accessing the zeroth segment, the trap is taken. If an exception
is detected partway through accessing a subsequent segment, vl is
reduced to the index of that segment. In both cases, it is
implementation-defined whether a subset of the segment is loaded.
